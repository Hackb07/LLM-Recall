# EXPERIMENT 7: Semantic Search using Sentence Embeddings

## AIM

To perform semantic search using Sentence-BERT embeddings and retrieve sentences based on the meaning of a query.

## ALGORITHM

1. Load the pre-trained Sentence-BERT model.
2. Prepare the sentence corpus.
3. Convert each sentence into a normalized embedding.
4. Convert the user query into an embedding.
5. Calculate cosine similarity and display the top matching sentences.

## CODE

```python
from sentence_transformers import SentenceTransformer, util


def main() -> None:
    model = SentenceTransformer("all-MiniLM-L6-v2")
    corpus = ["A man is eating food.",
              "A woman is playing violin.",
              "The phone has a good camera."]
    emb = model.encode(corpus, convert_to_tensor=True,
                       normalize_embeddings=True)
    query = "Someone is having a meal"
    q = model.encode(query, convert_to_tensor=True,
                     normalize_embeddings=True)

    print("Query:", query)
    hits = util.semantic_search(q, emb, top_k=2)[0]
    for h in hits:
        print(round(h["score"], 3), corpus[h["corpus_id"]])


if __name__ == "__main__":
    main()
```

## OUTPUT

```
Query: Someone is having a meal
1. A man is eating food.
2. A woman is playing violin.
```

(Similarity scores are generated by the model.)

## RESULT

Thus, semantic search using sentence embeddings was implemented and relevant sentences were retrieved successfully.
